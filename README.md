# TaskPin

A small, compact todo list that stays on top of your Windows desktop.

## Download

Download `TaskPin.exe` from [GitHub Releases](https://github.com/johanthorild/TaskPin/releases).

TaskPin is currently published for 64-bit Windows and does not require a separate .NET installation.

## Features

- Add, edit, complete, and delete tasks.
- Drag and drop tasks to reorder them.
- Resize the window from any edge or corner.
- Move the window by dragging any empty area.
- Minimize the window from the button or right-click menu.
- Adjust opacity and startup position in Settings.
- Keep tasks, task order, settings, and window size between sessions.

## Usage

- Type a task and press `Enter` or select `+`.
- Select a task's text to edit it.
- Use the drag handle to change a task's position.
- Right-click the window to open Settings, minimize TaskPin, or quit.

Tasks and settings are stored as JSON in `%AppData%\TaskPin`.
