# TaskPin

A small, compact todo list that always stays on top of your desktop.

## Run locally

```powershell
dotnet run
```

Tasks and settings are stored as JSON in `%AppData%\TaskPin`.

## Usage

- Type a task and press `Enter` or `+`.
- Check a task when it is complete.
- Drag the top edge to move the window.
- Right-click to open settings or quit.
